如果仍无法打开，请到 Edge 扩展管理页，找到「智囊」并点击重新加载。

开始使用

  1. 入口：以后双击桌面或开始菜单的「智囊」图标即可打开；也可以把 Edge 工具栏里的智囊图标固定到地址栏旁边（点右上角拼图 → 找到智囊 → 点图钉）。
  2. 登录：AI 平台登录状态保存在智囊窗口自己的配置里，首次使用请在各个窗格内重新登录一次（之后会一直记住）。
  3. 更新：每次打开智囊都会自动检查并安装新版本，无需手动更新。
  4. 旧版清理（仅老用户）：若此前用「开发者模式」装过旧版，请打开 Edge 的 edge://extensions 删除旧的「智囊」条目，只需一次。
