# 商店提审清单：智囊 · Braintrust（Windows 原生应用 → Microsoft Store）

> 使用前提：Microsoft Partner Center 开发者账号已注册通过（个人 $19 一次性 / 公司 $99 + D-U-N-S）。
> 本清单配合 `Windows/native/STORE_LISTING.md` 使用；所有「准备」项均可在账号审批期间完成。

## 一、账号下来后（Partner Center 操作，仅注册人可做）

- [ ] 仪表板 →「应用和游戏」→「创建新应用」→ 名称：**智囊 · Braintrust**（备选：Braintrust）
- [ ] 「产品管理 → 产品标识」取得三项正式值，替换 `Package.appxmanifest`：
      `<Identity Name>`、`<Identity Publisher>`、`<Properties><PublisherDisplayName>`
- [ ] `<Identity Version>` 设为提审版本（建议商店版从 `1.0.0.0` 起，与直发版 0.4.x 分离）
- [ ] 提交前用正式身份重新构建 MSIX（CI 产物为测试证书签名，仅内部验证用）

### 截图方案

CI 的 `live-test-msix` job 会输出工作台真实截图（六窗格加载状态，无登录）。
**上架截图建议在已登录各平台的 Windows 真机上截取**（登录态会带出更完整的视觉效果）：
1. 工作台全景（六窗格并排 + 顶部统一输入框）；
2. 统一提问 → 多平台并排回答效果；
3. 平台勾选与分页（1–3 窗格响应式）；
4. 附件注入；
5. 语音输入；
6. 登录备份菜单。
规格：1366×768 及以上、PNG/JPEG、桌面端截图。

## 三、年龄分级问卷（IARC）参考答案

按应用的**自身功能**如实填写（嵌入的第三方网站内容不归我们承载，但"网页浏览能力"要如实声明）：

| 问题 | 答案 | 说明 |
|---|---|---|
| 是否为浏览器/包含网页浏览功能 | **是** | 应用本质是多窗格浏览器 → 评级会相应提高，如实声明 |
| 用户生成内容 | 否 | 我们不承载、不展示自有 UGC 平台 |
| 购买/内购 | 否 | 免费、无内购 |
| 共享个人信息 | 否 | 无账号体系、无上传 |
| 共享位置 | 否 | — |
| 数字商品购买 | 否 | — |

预期评级：因浏览器功能声明，可能在部分市场评 12+ / 16+；如实填写即可，不影响审核通过。

## 四、隐私问卷（Microsoft Store 提交表单）参考答案

- 是否收集/传输用户数据：**否**（不运营服务器、无遥测、无分析 SDK）
- 是否包含第三方 SDK：**否**
- 数据存于何处：仅在用户本机（`%LOCALAPPDATA%\ParallelWorkbench\`）
- 隐私政策 URL：`PRIVACY.md` 的托管地址

## 五、提审步骤（账号 + 材料就绪后）

1. 「开始提交」→ 定价和可用性：免费；市场按需（建议先中国区）
2. 属性：类别 = 生产力
3. 年龄分级：按第三节答案
4. 程序包：上传正式身份 MSIX → 提交选项允许公众下载
5. 商店一览：描述/截图/隐私政策 URL/支持信息
6. 提交选项 → 认证说明粘贴 `STORE_LISTING.md` 的说明文案 → 提交
7. 审核通常 1–3 个工作日；通过后商店自动签名并分发，更新 = 新版本包重新提交（自动更新）

## 六、上线后的更新流程

- 版本号递增（`bump-version.sh`）→ 提交新 MSIX → 商店自动推送更新
- 平台改版（适配器/注入脚本变化）→ 推仓库后重新构建提交即可，用户无需任何操作
