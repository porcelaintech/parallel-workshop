# Windows 原生应用 · 提审前人工验收清单

> CI 的 `live-test-msix` 已自动验证：安装、启动、六窗格加载、15 秒稳定性、截图取证。
> 以下项目依赖真实硬件/登录态，需在 Windows 真机上人工逐项确认后提交商店。

## 准备

- [ ] 从 CI 产物下载 MSIX（测试证书签名）→ 双击安装（需信任测试证书）
- [ ] 或本地 VS 2022 构建运行（见 `Windows/native/README.md`）

## 逐项验收

### 基础

- [ ] 应用启动无报错，主窗口标题「智囊 · Braintrust」
- [ ] 六个平台窗格全部加载（ChatGPT / DeepSeek / 豆包 / Kimi / 通义 / 文心）
- [ ] 状态角标正确（就绪 / 未登录 / 未找到输入框 / 无响应）
- [ ] 平台勾选 → 窗格显隐与 1–3 窗格响应式分页正常
- [ ] 放大单窗格 / 缩放 / 刷新 / 回主页按钮正常

### 核心链路

- [ ] 顶部输入框输入问题 → Ctrl+Enter → 各勾选平台真实收到并生成回答
- [ ] 未登录平台诚实提示、不发送

### 登录（每个平台一次）

- [ ] DeepSeek：微信扫码登录在窗格内完成，不逃出应用
- [ ] DeepSeek：登录后切换模型 → 关闭重启应用 → 模型偏好保持（model-preference 注入）
- [ ] 豆包：手机号/扫码登录窗格内完成
- [ ] Kimi / 通义 / 文心 / ChatGPT：各自登录窗格内完成
- [ ] 登录态重启后保持；「登录态 → 备份/恢复」功能可用

### 附件与语音

- [ ] 选择/拖入图片或文件 → 附件 chips 显示 → 发送后各平台注入（input 通道平台文件名可见；drop 通道平台如实提示）
- [ ] 语音输入按钮 → 授权后说话 → 转写文字填入输入框（中文）

### 稳定性

- [ ] 连续使用 10 分钟无崩溃、无窗格白屏
- [ ] 关闭再启动：登录态、勾选、缩放偏好均保持

## 全部通过后

按 `docs/STORE_SUBMISSION_CHECKLIST.md` 执行提审（正式身份重建 MSIX → Partner Center 提交）。
