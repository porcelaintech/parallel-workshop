# 商店描述文案（Microsoft Store）

## 中文 · 短说明（一行，最多约 100 字）

一次提问，多位 AI 并排回答。智囊把 ChatGPT、DeepSeek、豆包、Kimi、通义千问和文心一言放进同一个窗口，统一输入、同步发送，保留各平台官方网页的完整体验。

## 中文 · 完整说明

智囊（Braintrust）是一个多模型平行问答工作台：

- **一个窗口，六位 AI 并排**：ChatGPT、DeepSeek、豆包、Kimi、通义千问、文心一言同屏显示，一次提问全部作答，回答并排对比；
- **统一输入，一键同步发送**：顶部输入框输入问题，Ctrl+Enter 同步发送到所有勾选的平台；
- **官方网页完整体验**：每个窗格都是平台官方网页客户端，功能、模型、登录方式与官网完全一致，你在窗格内正常登录即可；
- **登录态持久**：每个平台登录一次后持久保存，重启不丢；支持一键备份/恢复登录态；
- **灵活窗格**：勾选参与平台、放大单窗格、1–3 窗格响应式分页、逐窗格缩放与刷新；
- **附件与语音**：支持图片/文件附件同步注入，支持系统语音识别输入；
- **隐私友好**：不运营服务器、不收集数据——问题只从你的输入框复制到你自己登录的平台官方网页，登录态只保存在本机。

适合需要同时对比多个大模型回答、或需要跨平台同步提问效率的用户。

## English · Short description

Ask once, get answers from multiple AIs side by side. Braintrust puts ChatGPT, DeepSeek, Doubao, Kimi, Tongyi Qianwen and ERNIE Bot in one window with a single unified input.

## English · Full description

Braintrust is a multi-model parallel Q&A workbench:

- Six AIs side by side: ChatGPT, DeepSeek, Doubao, Kimi, Tongyi Qianwen and ERNIE Bot answer the same question at once, side by side for easy comparison.
- One input, one shortcut: type once, press Ctrl+Enter, and the question is sent to every selected platform.
- Official web experience: every pane is the platform's official web client — same features, models and login as the official site. Just sign in inside the pane.
- Persistent sign-in: log into each platform once; sessions persist locally, with one-click backup and restore.
- Flexible layout: select which platforms to send to, focus a single pane, responsive 1–3 pane paging, per-pane zoom and reload.
- Attachments and voice: sync image/file attachments to all panes, plus system speech-to-text input.
- Privacy friendly: no servers, no data collection — your questions are only copied from the input box into the official sites you are signed into; credentials never leave your device.

Perfect for anyone comparing answers across multiple AI models or syncing a question to several platforms at once.
