# 智囊 · Braintrust — 产品说明与代码解读

> 版本：v0.4.1｜ 交付形态：macOS 原生应用（Apple 芯片 + Intel 通用）+ Windows/Edge 浏览器扩展 ｜ 开源（GitHub 分发）

本版重点：品牌更新为「智囊 · Braintrust」纯文字标题；按平台提供直接执行安装命令的极简 Agent Prompt；Windows 桌面和开始菜单入口更明确；新启动页显示初始化状态并核对实际扩展版本，更新保留登录与偏好。

---

## 一、产品概述

**智囊（Braintrust）**是一个多模型平行比较工作台：把多个 AI 平台的官方网页端并排嵌入同一个窗口，输入一个问题，一键同步发送到所有勾选的平台，各平台回答并排呈现，方便横向比较。产品原名「平行工作台」，升级沿用原应用标识、扩展 ID 和数据目录。

核心设计原则：

1. **零 API 成本**：不调用任何付费 API，直接嵌入各平台官方网页端，复用用户已有登录态与免费额度。
2. **登录态持久**：macOS 版使用应用自带 WebKit 持久存储（在工作台窗格内登录一次即持久）；Windows 版与 Edge 浏览器共享登录态。
3. **登录不出框**：所有登录/验证流程被强制圈禁在工作台内，绝不弹窗逃逸到新窗口/新标签页。
4. **诚实降级**：任何注入/发送失败都明确可见（状态角标、toast、跳过提示），不做静默失败。
5. **双平台同核**：两平台共用同一套适配器与注入核心，一处适配、双端生效。

**不提供**：任何代理/VPN 能力（国际平台走用户自己的网络环境）；任何 API 集成。

## 三、安装与使用

### macOS 版

1. 解压交付包，进入 `macOS/`，双击 `ParallelWorkbench.app`。
2. 首次打开若提示「无法验证开发者」：右键点击 App → 「打开」→ 再点「打开」（本产品未签名，此为正常提示；签名/公证需 Apple Developer 账号）。
3. 首次使用时在工作台的各窗格内直接登录（登录流程被围栏圈禁在窗格内，不会跳出应用）；登录态持久保存，之后打开即用。
4. 输入问题（⌘↩ 发送），所有勾选平台同时收到问题；用 ◀ ▶ 翻页查看 3 个之外的窗格。
5. 附件：输入框下方 📎 选择文件、直接拖入、或 ⌘V 粘贴图片。部分平台不支持程序化附件（详见第七节），会明确提示手动添加。
6. 语音：点 🎤 开始说话，自动转写进输入框，再点一次结束。首次使用需在系统设置授权「麦克风」与「语音识别」。

### Windows/Edge 版

1. 解压交付包，进入 `Windows/edge-extension/`。
2. 双击 `install.bat`（自动复制到本地目录、创建桌面与开始菜单快捷方式、复制路径到剪贴板、打开扩展管理页）。
3. 在 `edge://extensions` 打开左下角「开发人员模式」，点「加载解压缩的扩展」，粘贴剪贴板里的路径，回车。
4. 使用前在 **Edge** 中登录各平台，扩展窗格自动继承登录态。
5. 双击桌面「智囊」启动，或在开始菜单搜索「智囊」。启动页显示初始化状态，并在进入工作台前核对实际扩展版本；若 Edge 仍加载旧版，会重新加载本扩展并恢复工作台。
6. 首次发送时 Edge 会询问「允许扩展调试此浏览器吗？」——这是附件拖放通道所需权限，允许即可；拒绝则附件功能退化为手动添加，其余功能不受影响。

> 开发者模式与调试器权限是「浏览器扩展侧载」的正常要求；上架 Edge 加载项商店后可免除，见第十节。

## 四、技术架构总览

```
┌──────────────────────────────────────────────────────────────┐
│                     共享核心（单一事实来源）                     │
│  Sources/WorkbenchCore/Resources/                             │
│   ├── adapters/*.json  平台适配器（选择器/发送策略/探测规则）      │
│   └── injection/{inject.js, probe.js}  注入与探测核心（纯 JS）   │
└───────────────┬──────────────────────────┬────────────────────┘
                │ 复制                        │ 构建时转换内嵌
        ┌───────▼────────┐          ┌────────▼─────────────────┐
        │  macOS 原生应用  │          │   Edge MV3 扩展           │
        │ SwiftUI + WKWebView │      │  扩展页 + iframe 窗格      │
        │ evaluateJavaScript │      │ content_scripts + tabs.sendMessage │
        │ （不受 CSP 限制）   │      │  （隔离世界，跨帧消息协议）     │
        └────────────────┘          └──────────────────────────┘
```

- **适配器（adapter JSON）**：每个平台一份配置——输入框选择器、发送策略（回车/按钮/pointer 序列/段落插入）、登录/验证探测规则、附件输入框选择器、主页域名等。改平台适配 = 改 JSON，双端同时生效。
- **注入核心（inject.js）**：一段异步脚本，把文本写进目标编辑器（textarea 用原生 setter + 事件；contenteditable 用 execCommand 并同步选区；Slate/Lexical/ProseMirror 各自兼容），可选注入附件，再按策略触发发送。执行结果写入 `window.__wb_result`。
- **探测核心（probe.js）**：同步返回 `{input, challenge, loggedOut, loginModal, url}`，供状态角标显示。

## 五、核心机制详解

### 1. 注入协议（双端一致）

macOS：`WKWebView.evaluateJavaScript` 在页面上下文直接执行（原生通道，不受页面 CSP 的 `unsafe-eval` 限制）；Swift 轮询 `window.__wb_result` 取结果（WebKit 不 await Promise）。

Edge：内容脚本跑在**隔离世界**。工作台先用 `webNavigation` 解析目标 `frameId`，再通过 `chrome.tabs.sendMessage` 把 `WB_INJECT` / `WB_PROBE` / `WB_ATTACH_CHECK` 直接送达该 frame；结果通过扩展运行时回执返回，不经过页面主世界。构建时把 inject.js/probe.js 转成无 eval 的普通函数内嵌进 content.js。

### 2. 编辑器框架兼容（五种输入策略）

| 平台 | 编辑器 | 策略 |
|---|---|---|
| DeepSeek | textarea | `enter`（原生 setter 设值 + 合成回车） |
| 豆包 | ProseMirror（contenteditable） | `button`（语义编辑器设值 + `flow-end-msg-send`） |
| Kimi | Lexical（contenteditable） | `button`（选区同步 + 段落插入 + 点击发送按钮） |
| 通义千问 | Slate（contenteditable） | `pointer`（完整 pointer/mouse 事件序列点击发送） |
| 文心一言 | textarea | `enter` |
| ChatGPT | ProseMirror（textarea 输入） | `button`（aria-label 定位发送按钮） |

### 3. 附件（多模态）通道——按平台选择，互斥防重复注入

- **文件输入框赋值（主通道）**：隔离世界重建 `File` → `input.files = dt.files` → 派发 change → 走平台原生上传管线。实测：**Kimi**（文件进入解析管线，页面出现上传卡）、**ChatGPT**（附件 chip 出现）均验证成功。
- **CDP 拖放（兜底通道）**：无文件输入框的平台（通义/文心）用 `chrome.debugger` 的 `Input.dispatchDragEvent` 在页面坐标派发拖放（页面侧计算坐标：iframe 框位置 × CSS 缩放 + 帧内编辑器中心；命中测试跨 OOPIF 投递）。**平台限制**：扩展无文件系统权限，CDP 只能投递 MIME 数据（无法构造真实 File），严格检查 File 类型的平台会拒绝。
- **诚实降级**：注入后询问内容脚本「文件名是否出现在页面」→ 未接受则 toast「附件未被平台接受，请手动添加」。
- **实测矩阵**：Kimi ✅ / ChatGPT ✅ / DeepSeek ⚠️（赋值成功但疑似要求真实用户手势）/ 通义 ❌ / 文心 ❌。

### 4. 登录围栏（防逃逸）

- macOS：WKWebView `createWebViewWith` 把一切新窗口请求圈回当前 webview。
- Edge 登录边界：
  1. 平台 iframe 使用 sandbox，阻止认证子帧导航整个工作台；
  2. 后台仅为已注册的工作台 tab 创建 session DNR rule，按 `tabIds` 剥离目标子帧的 `X-Frame-Options`/`CSP`；
  3. DeepSeek 微信 QR 授权由 `intercept.js` 捕获 callback 候选，经隔离 `auth-bridge.js` 和后台两次白名单校验后，只导航 DeepSeek pane，并以 probe 验证真实登录态。

### 5. 登录态继承

- macOS：应用自带的 `WKWebsiteDataStore.default()` 持久存储（`~/Library/WebKit/ParallelWorkbench`），登录态保存在应用内，与 Safari 隔离；登录请在窗格内完成。
- Edge：扩展窗格 iframe 与浏览器共享站点存储。
- macOS 额外提供登录态备份/恢复：`--backup-auth` 归档 `~/Library/WebKit/ParallelWorkbench` 与 `HTTPStorages/ParallelWorkbench.binarycookies`（会话过期后可恢复）。

### 6. 版本更新

- 双端顶部固定显示 `Update` 和当前版本；启动、回到前台及每 6 小时检查 GitHub Releases 最新稳定版，短时间重复回前台会合并检查。
- 状态明确区分「已是最新版」、可用新版、网络超时与服务错误；失败可重试，不把检查失败当成已是最新版。
- GitHub API 受限或暂时不可用时读取同仓库 Latest Release 的 `update.json`，校验版本、资产 URL 与 SHA-256 后继续更新。
- macOS：点击 `Update` → 下载 DMG → 校验 SHA-256 → 安装 → 等待旧 PID 退出 → 重启新版，避免启动请求复用旧进程。
- Edge：侧载版下载并校验 `edge-extension.zip` → 解压 → 运行 `install.bat` → 启动页核对版本并重新加载本扩展；Edge Add-ons 渠道使用浏览器原生安装与重载。

### 7. 语音输入

- macOS：`SFSpeechRecognizer` 实时转写叠加进输入框；是否使用设备端识别取决于系统与语言能力，Info.plist 声明麦克风/语音识别用途。
- Edge：Web Speech API（`SpeechRecognition`，中文），interim 结果实时更新输入框；权限拒绝/不支持时明确提示。

## 八、测试与质量保障

- **本地夹具自检（9 项，不触网）**：五种发送策略、两种附件注入、NO_INPUT 回退、probe 探测——`qa.sh` 一键执行。

- **macOS 真机验收**：原有 5 个平台完成真实发送回归；豆包完成 iframe、注入与未登录状态探测。
- **质量门禁**：`bash scripts/qa.sh`（Swift 构建 → 自检 → 扩展语法/JSON 校验 → jsdom 胶水层冒烟）。
