安装与使用

智囊是一个本地应用：安装后桌面会出现「智囊」图标，点开就是工作台。它不需要浏览器扩展，也不需要 Apple 公证或 Windows 代码签名证书；代价是第一次安装时系统会给出一次安全提示。

0.6.0 开发中：本文档描述的是公开版的目标行为。当前内测包可能还没有完整的并行窗格、自动更新或全部平台适配；请以首页下载区的状态为准。

安装前

智囊支持 macOS 13 Ventura 及以上（Apple 芯片与 Intel）和 Windows 10 / 11 64 位。安装包内置 Node 22 运行时，不需要你另外安装 Node；浏览器使用系统的 Edge / Chrome / Chromium。安装不需要管理员权限，也不会写入系统级目录。

为什么没有公证也会提示？ macOS 的 Gatekeeper 和 Windows 的 SmartScreen 会检查下载来源。我们没有申请 Apple Developer 会员（$99/年）或 Windows 代码签名证书，所以第一次运行安装器会看到一次提示。按下面的步骤右键打开即可；安装器在本机生成的 智囊.app 不会带下载隔离标记，之后正常双击。

macOS 安装

  1. 从官网下载 Braintrust-local-service-macos-*.zip，解压。
  2. 双击 install.command。如果系统提示“无法打开，因为无法验证开发者”，右键点击 install.command → 打开 → 再点“打开”。
  3. 安装器会把服务复制到用户目录，并在 ~/Applications 生成本地 智囊.app，同时在桌面创建别名。
  4. 双击 智囊.app（或桌面「智囊」）打开工作台。第一次启动会打开一个独立的浏览器 Profile；如果系统里没有 Edge/Chrome/Chromium，会提示你先安装一个。
  5. 建议把 智囊.app 拖到 Dock，之后每天点 Dock 图标即可。

如果右键“打开”仍被拦截，到 系统设置 → 隐私与安全性，在“安全性”区域点“仍要打开”。这是 macOS 对未公证下载文件的系统级限制，不是智囊的崩溃。

不要在终端里用 sudo 安装。智囊只写当前用户目录；用 sudo 会把文件所有者改成 root，后续更新和浏览器 Profile 会出问题。

Windows 安装

  1. 从官网下载 Braintrust-local-service-windows-*.zip，解压到普通文件夹（不要直接在压缩包里双击）。
  2. 双击 install.bat。如果出现“Windows 已保护你的电脑”，点“更多信息” → “仍要运行”。
  3. 安装器会复制服务到 %LOCALAPPDATA%\Braintrust\service，并在桌面和开始菜单创建带图标的「智囊」快捷方式，不需要管理员权限。
  4. 双击「智囊」打开。首次启动会使用独立的 Edge/Chrome Profile；如果找不到浏览器，会提示安装 Microsoft Edge 或 Google Chrome。
  5. 可以右键任务栏图标选择“固定到任务栏”，或把桌面快捷方式固定到开始菜单。

如果 install.bat 被浏览器标记为“已阻止”，右键文件 → 属性 → 勾选“解除锁定” → 确定，再运行。Windows 的 Mark-of-the-Web 会对下载的脚本生效；这不是病毒提示，但请始终从 braintrust.chat 或我们的 GitHub Release 下载。

首次启动

安装器不会在后台偷偷启动一个常驻服务。你双击图标时，启动器会：

  • 检查本地服务是否已经在运行；如果已经在运行，直接把工作台窗口带到前台；
  • 如果没运行，启动本地 Node 服务，再打开工作台的浏览器窗口；
  • 如果端口被占用或浏览器缺失，给出可见的错误提示和日志路径。

服务只监听 127.0.0.1，不会暴露到局域网或公网。每次启动会生成一次性 API token；工作台页面通过本地 token 调用服务。

登录与发送

智囊不创建账号，也不托管你的登录态。你在每个平台的窗格里登录官方网页；登录 Cookie 保存在智囊自己的浏览器 Profile 中，和日常浏览器隔离。

  • 第一次使用：逐个打开平台窗格，用各平台官方方式登录（扫码、密码、验证码都由平台页面处理）。
  • 发送：勾选要参与的平台，输入问题，点发送。智囊把问题填入各平台输入框并触发发送；回答留在各平台原生界面里。
  • 附件：只发送给你勾选的平台；智囊不会把附件上传到自己的服务器。
  • 如果平台要求人机验证，请在对应窗格里手动完成；智囊不会绕过验证。

更新

应用内“检查更新”会读取 https://braintrust.chat/updates/local-service-update.json，然后从 GitHub Release 下载新安装包并校验 SHA-256。更新索引和安装包都不包含你的提问、附件或登录态。

更新只替换程序文件，不删除 data 目录；登录态和本地附件会保留。如果更新失败，旧版本继续可用。

数据与卸载

智囊在本机保存以下内容：

  • 程序文件：安装目录（可删除，重新安装会恢复）。
  • 浏览器 Profile：各平台登录 Cookie、缓存、页面存储。
  • 本地数据：服务锁、日志、更新缓存；提问和附件按平台页面自身机制处理，智囊不另建云端副本。

卸载 macOS：把 ~/Applications/智囊.app 拖到废纸篓；如需彻底清除登录态，再删除 ~/Library/Application Support/Braintrust。

卸载 Windows：删除桌面和开始菜单的「智囊」快捷方式；如需彻底清除，再删除 %LOCALAPPDATA%\Braintrust。

删除数据目录会同时删除登录态和本地附件。如果只是想换版本，不要删 data。

故障排查

macOS 提示“无法验证开发者”

右键 install.command → 打开 → 再点“打开”。安装完成后，本机生成的 智囊.app 不应再被拦截；如果仍被拦截，到系统设置 → 隐私与安全性 → “仍要打开”。

Windows 提示“Windows 已保护你的电脑”

点“更多信息” → “仍要运行”。如果文件属性里有“解除锁定”，先勾选再运行。

提示找不到浏览器

安装 Microsoft Edge 或 Google Chrome 后重试。智囊不会使用 Safari 或 Firefox 的内核；它需要 Chromium 系的浏览器来承载平台页面和调试协议。

点图标没有反应 / 第二次点打不开

先看日志：macOS ~/Library/Logs/Braintrust/service.log；Windows %LOCALAPPDATA%\Braintrust\logs\service.log。如果提示“已经在运行”，说明后台服务还在；新版本启动器会直接打开已有窗口。如果窗口被关掉，再点一次图标即可。

端口被占用

智囊默认使用一个本地端口；如果被其他程序占用，启动器会换一个端口并写入发现文件。若反复失败，重启电脑后再试。

平台页面改版，发送失败

平台改版会导致输入框/发送按钮选择器失效。请在 GitHub Issues 反馈平台名称和截图；不要在里面贴登录凭证或隐私对话。
