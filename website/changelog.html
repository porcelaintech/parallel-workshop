更新日志

本地工作台还在 0.6.0 的开发阶段。下面区分“已发布的内部版本”和“计划中的公开版本”，避免把未完成的功能写成已上线。

0.6.0 — 公开版本（开发中）

  • 设计版工作台：顶部统一输入、附件栏、平台勾选、1–3 个并行窗格、分页、缩放、状态角标。
  • 桌面入口：安装后生成本地 智囊.app / Windows 快捷方式；再点图标找回已有窗口。
  • 安装包内置 Node 22；浏览器使用系统 Edge / Chrome / Chromium，不需要下载 Node。
  • 更新索引迁到 braintrust.chat，安装包从 GitHub Release 下载并校验 SHA-256。
  • 不申请 Apple 公证、不申请 Windows 代码签名；安装器在本机生成应用，首次安装会看到一次系统提示。

状态：开发中。下载按钮会在 GitHub Release 发布并部署更新索引后自动开放。

0.5.0 — 内部技术预览

  • 本地 Node 服务、六个平台适配器、独立浏览器 Profile、CDP 探针/发送。
  • 极简控制页（非设计版工作台），仅用于内部验证服务链路。
  • 未公开下载。
