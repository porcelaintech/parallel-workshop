WHY LOCAL

为什么是本地应用

不是把网页塞进另一个网页，也不是再做一个需要用户去找图标的浏览器扩展。智囊是一个有桌面入口的本地应用。

01

桌面图标，不藏在扩展栏

安装后桌面、开始菜单或 Applications 里有「智囊」。点一下打开；再点一下回到已有窗口，不需要记住端口，也不需要去浏览器扩展菜单里找。

02

一次输入，六端并排

勾选要参与的平台，输入一次问题，统一发送。每个平台保留自己的原生界面、登录态和回答，不需要复制粘贴。

03

数据边界在你这台电脑

智囊没有账号系统，不经过我们的服务器。登录态保存在独立浏览器 Profile；提问和附件只发给你勾选的 AI 平台。

HOW IT WORKS

三步开始

第一次安装需要解压并运行安装器；之后每天只需要点桌面图标。

下载并安装

macOS 双击 install.command；Windows 双击 install.bat。安装器会生成本地「智囊」图标，不需要 Apple 公证或 Windows 代码签名证书。

在窗格里登录平台

打开智囊后，在对应平台的窗格内登录官方网页。登录态保存在智囊自己的浏览器 Profile，不读取你日常浏览器的 Cookie。

输入一次，统一发送

勾选要参与的平台，输入问题，点发送。回答在各平台原生界面中并排展示；附件也只发送给你勾选的平台。

你的登录态，不该成为我们的数据。

智囊不建账号、不做会员、不代理对话。登录态和附件默认只在本机；更新检查只读取一份静态版本清单，不携带你的提问或 Cookie。

FAQ

常见问题

没有 Apple 公证、也没有 Windows 代码签名，所以第一次安装会看到系统提示。下面说明怎么处理。

macOS 提示“无法验证开发者”，怎么办？

因为我们没有申请 Apple Developer 会员，也没有做公证。第一次双击 install.command 时，右键点击文件 → 选择“打开” → 在弹窗里再点“打开”。安装器会在本机生成 智囊.app，这个 App 是在你电脑上生成的，不会带下载隔离标记，之后正常双击即可。详见 macOS 安装说明。

Windows 提示“Windows 已保护你的电脑”，怎么办？

点“更多信息” → “仍要运行”。我们没有购买 Windows 代码签名证书，所以 SmartScreen 会提示。安装器只在你自己的用户目录写入文件并创建快捷方式，不需要管理员权限。详见 Windows 安装说明。

需要安装浏览器吗？

智囊使用 Edge、Chrome 或 Chromium 的内核来承载各平台官方网页。Windows 10/11 自带 Edge；macOS 如果没有 Chrome/Edge/Chromium，安装器会提示你先安装一个。我们不会读取你日常浏览器的登录态，智囊使用独立 Profile。

智囊会把我的登录态或问题上传给你们吗？

不会。智囊没有账号系统，也没有我们的中转服务器。登录态保存在本机独立浏览器 Profile；提问和附件只发送给你勾选的 AI 平台。更新检查只请求 braintrust.chat 上的一份静态版本清单。

怎么更新？

应用内会检查 https://braintrust.chat/updates/local-service-update.json，下载 GitHub Release 上的新安装包并校验 SHA-256。更新不会动你的登录态和本地附件。

怎么卸载？

macOS：把 ~/Applications/智囊.app 拖到废纸篓，再删除 ~/Library/Application Support/Braintrust。Windows：删除桌面/开始菜单快捷方式，再删除 %LOCALAPPDATA%\Braintrust。删除数据目录会同时删除登录态和本地附件。
