隐私说明

智囊是一个本地应用。我们没有账号系统，也没有中转你对话的服务器。下面用尽量直白的语言说明数据在哪里、会去哪里。

一句话版本

智囊不建账号、不运营中转服务器、不读取你日常浏览器的 Cookie。登录态和附件默认只在你电脑上；只有你勾选的 AI 平台会收到你发送的内容。

留在本机的东西

安装后，智囊会在当前用户目录写入：

内容macOSWindows
程序文件~/Library/Application Support/Braintrust/service%LOCALAPPDATA%\Braintrust\service
浏览器 Profile.../Braintrust/data/browser-profile%LOCALAPPDATA%\Braintrust\data\browser-profile
本地状态 / 日志.../Braintrust/data、~/Library/Logs/Braintrust%LOCALAPPDATA%\Braintrust\data、...\logs

浏览器 Profile 保存各平台的登录 Cookie、页面缓存和站点存储。它和你的日常浏览器是隔离的；智囊不会读取你日常浏览器里的 Cookie。

会发给谁

当你在工作台输入问题、添加附件并点发送时，内容会被填入你勾选的平台官方网页，并由该平台页面按它自己的方式提交。也就是说：

  • 你勾选 ChatGPT，内容就发给 OpenAI 的页面；你勾选 DeepSeek，就发给 DeepSeek 的页面。
  • 平台如何处理、保存、用于训练，取决于该平台的隐私政策，不由智囊控制。
  • 智囊不把内容额外上传到 braintrust.chat 或我们的服务器；我们没有这样的中转接口。
  • 附件只进入你勾选的平台的页面；智囊不在本地另建云端副本。

我们不收集什么

  • 不建立智囊账号，不收集姓名、手机号、邮箱或会员信息。
  • 不上传你的平台登录 Cookie、密码或扫码凭证。
  • 不收集你的提问、附件或回答内容到我们的服务器。
  • 不在应用内埋点、不做行为分析、不接入第三方统计 SDK。

更新检查

应用内“检查更新”会请求 https://braintrust.chat/updates/local-service-update.json。这是一份静态 JSON，只包含版本号、发布时间、安装包 URL 和 SHA-256；请求不携带你的提问、附件、Cookie 或设备标识。

安装包从 GitHub Release 下载；下载过程会经过 GitHub 的服务器，GitHub 可能按其政策记录 IP 和下载日志。我们不在下载链接里附加用户标识。

官网与下载

这个官网是纯静态页面：没有登录、没有评论、没有联系表单，也没有广告或第三方分析脚本。我们不在页面里设置用于追踪的 Cookie。

如果你从官网跳到 GitHub、或从 GitHub 下载安装包，相关请求由 GitHub 处理，适用 GitHub 的隐私政策。

删除数据

macOS：把 ~/Applications/智囊.app 拖到废纸篓；彻底删除登录态和本地数据，再删除 ~/Library/Application Support/Braintrust 和 ~/Library/Logs/Braintrust。

Windows：删除桌面/开始菜单快捷方式；彻底删除再删除 %LOCALAPPDATA%\Braintrust。

删除数据目录会同时删除登录态和本地附件。如果只是想升级版本，不要删 data 目录。

联系

隐私相关问题可以通过 GitHub Issues 反馈。请不要在公开 issue 里贴登录凭证、Cookie 或私人对话。
